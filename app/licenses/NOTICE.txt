The LG text-model keyboard adapter is based on SDL-webOS by Mariotaku.
It is modified for LeanTube. See SDL-webOS.txt for its license.

LeanTube uses SDL_ttf for text rendering.
This software is based in part on the work of the FreeType Team.
Portions of this software are copyright 2026 The FreeType Project
(https://freetype.org). All rights reserved.

SDL3, Wayland, libffi, and xkbcommon use the licenses in this directory.
The app includes private curl, OpenSSL, zlib, nghttp3, and ngtcp2 libraries.
Their licenses are curl.txt, OpenSSL.txt, zlib.txt, nghttp3.txt, sfparse.txt,
and ngtcp2.txt in the packaged licenses directory.
GCC runtime libraries use GPL version 3 with the GCC Runtime Library
Exception version 3.1. See GPL-3.0.txt and GCC-runtime.txt.

The bundled fonts use the SIL Open Font License in fonts/OFL.txt.
Emoji use the installed system font, which is not redistributed.
Text shaping uses HarfBuzz, under HarfBuzz.txt.
Geist Mono has been modified: Unicode zero uses the original font's ss09
plain-zero glyph. All other glyphs and the original font names are retained.

SDL_image loads WebP and JPEG covers and rasterizes SVG icons. It includes
libwebp, NanoSVG, and stb_image. Their license and patent notices are in this
directory. stb_image is used under its public-domain license.
The Lucide icons use the license in icons/LICENSE.

LeanTube uses SponsorBlock data from https://sponsor.ajay.app/ under
CC BY-NC-SA 4.0: https://creativecommons.org/licenses/by-nc-sa/4.0/.

QR Code generation uses Project Nayuki's qrcodegen under the MIT License.
See qrcodegen.txt.

Native playback uses the Starfish C interface from SS4S
by Mariotaku, revision dfba721b85420ccabf91dac65be73984bf1865f9,
under LGPL version 3, with small LeanTube additions for playback rate
and video capabilities. See Starfish-wrapper.txt and GPL-3.0.txt.
Its source and build instructions are in vendor/starfish. The adapter
is a separate, replaceable shared library. It is not a playback engine.
The installed LG library and system C++ runtime are not redistributed.
